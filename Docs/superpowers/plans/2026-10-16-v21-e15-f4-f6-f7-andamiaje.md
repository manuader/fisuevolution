## F6 — VEJ v2: modelo de árboles

**Lo que dice R8:** ~3,3 instalaciones por jugador etiquetado; 5–10 mil etiquetados ≈ 17–33 mil instalaciones; sin
dato de instalaciones/día de la v1 no hay fecha. Las reglas de F1 probablemente alcancen mucho tiempo. **Todo lo de F6
que no es entrenar se hace ya**, así el día que haya datos sólo falta correr el script y publicar.

### C1 — El formato del modelo (JSON de árboles)

```json
{ "version": "tree-1", "features": ["country_tier", "device_tier", "rewarded_count", "avg_rewarded_micros", "…"],
  "base_score": 0.0, "link": "expm1",
  "trees": [ { "left": [1, -1, -1], "right": [2, -1, -1], "feature": [0, -1, -1], "threshold": [1.5, 0, 0],
               "default_left": [true, true, true], "value": [0, 0.12, -0.03] } ] }
```

Es la forma que exporta XGBoost (`dump_model` en JSON, aplanado por árbol) y la que el reel muestra en `runModel()`
(`left_children`, `right_children`, `split_conditions`, `base_weights`, `expm1`). LightGBM se convierte al mismo formato
en el script. Tope: 500 árboles, profundidad 8, 256 KB.
