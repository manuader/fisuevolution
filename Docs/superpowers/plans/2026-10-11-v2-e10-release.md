## Global Constraints

- **Nada sale de la máquina sin 🔒.** Prohibido para un agente: `xcodebuild -exportArchive` con
  `Distribution/ExportOptions.plist` (sube directo), `releaseops asc apply`, `asc listing apply`,
  `asc screenshot`, `admob set-id`, `git push` de `adergames-site` (Vercel despliega), enviar a
  TestFlight o a revisión, aceptar acuerdos, tocar App Privacy, el cuestionario de edad o un panel
  de red. Los comandos de lectura (`validate`, `asc status/plan/diff/ready`, `asc listing plan/diff`,
  `admob plan`, `version bump --dry-run`, `curl` a lo publicado) sí.
- **Credenciales fuera del repo** (`~/.appstoreconnect/releaseops.json`, la `.p8` con 600). El
  agente no crea keys ni tipea contraseñas o 2FA; si faltan, para con `NEEDS_CONTEXT`.

  `2TS7P7VDQJ`). Si `xcodebuild archive` pide un certificado, un perfil o el llavero, se para: 🔒.

  más Google. Ningún texto nuevo nombra a AppLovin ni a Mintegral; los que los nombran se corrigen.

  el rechazo ITMS-91064 (la v1, dos veces). Sólo T14, con los dominios del dueño.
- **Un dueño por archivo.** `release.json` tiene un solo dueño por ola (T5, T11); `project.yml` es 🔥
  (sólo T12, al final); `AppStoreScreenshotTests.swift` es de T6/T9; `Tools/releaseops/releaseops.py`

- **Prohibido `find /`** y toda búsqueda fuera del worktree (y de `adergames-site` en T4). El
  protocolo de agente: `/Users/manuader/Desktop/projects/FisuEvolution/.claude/worktrees/version-2/.superpowers/sdd/v2-agente-protocolo.md`.

**Objetivo:** que «verificar en el `.app`» de PLAN-v2 §8 sea un comando que da exit 0/1, no una

  `release.json → admob.appId`, `mediation.networks`.
- Produces:

```python

OWN_SKADNETWORK = {            # el ID propio de cada red; el resto de su lista se compara contra el fuente
    "google": ["cstr6suwn9"],
    "unity": ["4dzt52r2t5"],
    "meta": ["v9wttpbfk9", "n38lu8286q"],
}

@dataclass
class Check:
    name: str      # "UIDeviceFamily", "UIRequiresFullScreen", "NSPrivacyTracking", ...
    ok: bool
    detail: str    # qué se esperaba y qué hay

def locate_app(path: Path) -> Path                      # acepta .app o .xcarchive
def verify(app: Path, source_info: Path, source_privacy: Path, config: dict) -> list[Check]
```

Los chequeos (uno por fila de PLAN-v2 §8, más dos que el archive necesita):
